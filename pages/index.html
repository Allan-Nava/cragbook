cragbook

A climbing diary on cragcast's crags and routes: mark a route climbed (and the day), a project, or one to try, with a note.

  • Try the demo →The page with no server: crags read from cragcast, your diary kept in this browser.
  • API reference →OpenAPI 3.1, tested against the handlers on every change.
  • Source →Go and React, MIT licence; releases on GHCR for amd64 and arm64.

Run it

One container; the diary in memory here, in PostgreSQL with Docker Compose (see the README):

docker run --rm -p 8080:8080 -e CRAGBOOK_STORE=memory ghcr.io/allan-nava/cragbook:latest

What it does

  • Crags searched by name or municipality, with how many of their routes you have climbed.
  • A crag's routes grouped by level, easiest first, each with its diary entry.
  • The diary: climbed first, latest day first, then projects, then routes to try.
  • Imports from cragcast never touch the diary; a route gone from OpenStreetMap stays while it has an entry.
